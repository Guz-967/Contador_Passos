
# Contador de Passos

Projeto desenvolvido em HTML5, CSS3 e JavaScript com o objetivo de praticar  manipulação do DOM, lógica de programação, POO, OO, Getter, Setter e incremento de variáveis por meio da implementação de um site que exibe a contagem de passos na tela.

## Sobre o Projeto

O “Contador de Passos” é uma interface gráfica que permite ao usuário clicar em um botão para incrementar sua quantidade de passos. 

### Funcionalidades

- Escolha seu nome para contar os passos;
- Botão para incrementar os passos;
- Atualzação dos status exibida na tela;

### Como executar?

1. Execute o projeto
2. Digite o nome do usuário 
3. Clique no botão "Andar"
4. Acompanhe a quantidade de passos em tempo real
